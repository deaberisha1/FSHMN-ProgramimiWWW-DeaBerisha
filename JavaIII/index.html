Shpjegim: box-sizing dhe box model

CSS box model ka: content → padding → border → margin.

content-box (default)
width: 200px + padding: 20px + border: 3px
= 246px reale
border-box ★
width: 200px (perfshine gjithcka)
= 200px reale

Me box-sizing: border-box, width perfshine padding + border brenda vetes. Pa ate, padding dhe border shtohen jashte width e kjo tani shkakton overflow. Kjo ishte gabimi ne gabime.css: 700px + 80px padding x 2 = 860px.
